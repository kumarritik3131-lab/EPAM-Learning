# Basic AI Agent Workflow

## Introduction
A simple way to understand an AI agent is to follow the steps between receiving a request and returning a result. Not every agent follows exactly the same process.

## Key Concepts
1. **Receive a request:** The agent gets a task from the user.
2. **Understand the task:** It identifies the goal and important details.
3. **Choose a step:** It decides what action may help.
4. **Use a tool or act:** It may call a function or search a source.
5. **Check and respond:** It considers the result and provides an answer.

## Simple Example
Request: "Find the definition of supervised learning."
- The agent recognises that the user wants a definition.
- It chooses a knowledge-search tool.
- The tool retrieves the explanation.
- The agent presents it.

`User Request → Understand → Choose Action → Execute → Check Result → Respond`

## Practical Applications
This workflow can be used in a study helper, FAQ assistant or simple task organiser.
