# Tools and Function Calling

## Introduction
A tool is a capability an AI agent can use to complete part of a task. A tool might search information, perform a calculation or retrieve a record. Function calling allows an agent system to request that a particular function be run.

## Key Concepts
1. **Tool:** A capability made available to an agent, such as a calculator.
2. **Function:** A named block of code that performs a particular task.
3. **Tool selection:** Choosing a suitable tool based on the user's request.
4. **Arguments:** Information passed to a function, such as numbers for a calculation.
5. **Tool result:** The output returned by the function.

## Simple Example
A user asks, "What is 15 multiplied by 4?" The agent selects a calculator function, passes 15 and 4, receives 60 and reports the result.

## Practical Applications
Tools can let agents search approved documents, calculate values, look up information or interact with permitted software services. Tool access should be controlled.

## My Understanding
I understand tools as capabilities that extend what an agent can do. Function calling connects an agent's decision to code that performs a task.
