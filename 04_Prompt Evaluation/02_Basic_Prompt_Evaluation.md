# Basic Prompt Evaluation

## Introduction
Prompt evaluation means checking whether an AI response meets the needs of a task. It can also help compare prompts and identify ways to improve them.

## Key Concepts
1. **Relevance:** Does the response answer the question?
2. **Accuracy:** Are the facts correct? Important claims may need checking against reliable sources.
3. **Clarity:** Is the response understandable and organised?
4. **Completeness:** Does it cover the important parts of the request?
5. **Consistency:** Does it follow the same requirements across similar tasks?

## Simple Example
Suppose a prompt asks for three beginner tips for saving electricity. A good response should give three relevant, clear and accurate tips, not just one.

## Practical Applications
Prompt evaluation is useful when creating study material, comparing summaries, checking support responses or improving repeated AI tasks.

## My Understanding
I understand prompt evaluation as reviewing both the prompt and the response. A response should be judged against clear criteria rather than simply sounding confident.
