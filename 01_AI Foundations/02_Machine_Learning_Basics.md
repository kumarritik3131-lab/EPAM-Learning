# Machine Learning Basics

## Introduction
Machine Learning (ML) is a part of AI. It allows computers to learn patterns from data and use those patterns to make predictions or decisions.

## Key Concepts
1. **Data:** Examples used by an ML system to learn.
2. **Features:** Input details used by a model. For a house-price model, features might include area and location.
3. **Model:** A system that learns patterns from data and produces predictions.
4. **Training and testing:** Training data teaches a model; test data helps check how well it works on unseen examples.
5. **Learning types:** Supervised learning uses examples with known answers; unsupervised learning finds patterns without supplied answers; reinforcement learning learns through actions and rewards.

## Simple Examples
- Supervised: predicting house prices from past sales.
- Unsupervised: grouping customers with similar shopping habits.
- Reinforcement: training a game-playing system using rewards.

## Practical Applications
ML is used for spam detection, recommendations, demand forecasting, fraud detection and image classification.
