# Understanding Tokens

## Introduction
AI language models process text as tokens. A token can be a whole word, part of a word, a number or punctuation. Tokens are units a model uses when reading and generating text.

## Key Concepts
1. **Tokenization:** The process of splitting text into tokens.
2. **Words and tokens differ:** One word may be one token or several. Token counts are not always the same as word counts.
3. **Input tokens:** Tokens in the prompt and other information provided to the model.
4. **Output tokens:** Tokens generated by the model in its response.
5. **Context window:** The amount of text, measured in tokens, that a model can consider at one time. The limit depends on the model.

## Simple Example
The sentence "AI can help students learn." is split into tokens by a model's tokenizer. The exact pieces depend on the tokenizer, so it is not safe to assume every word equals one token.

## Practical Applications
Understanding tokens helps estimate how much text is being sent, work within context limits and decide when a long document should be shortened or divided.

## My Understanding
I understand tokens as small text units that language models process. Tokens are not exactly the same as words, and different models may split the same text differently.
